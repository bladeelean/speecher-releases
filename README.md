# Speecher for macOS

Official installers for [Speecher](https://saportino.com), a local dictation app.

Download the DMG from [Releases](https://github.com/bladeelean/speecher-releases/releases).

Requires an Apple Silicon Mac and macOS 13 or later. Open the DMG and drag Speecher into Applications.

Version 0.1.2 uses an ad-hoc signature and is not notarized by Apple. macOS may require explicit approval in System Settings → Privacy & Security on first launch.

This repository distributes installers and release notes; application source code is not included.
